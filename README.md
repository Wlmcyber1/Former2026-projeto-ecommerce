# 🐻 Performa E-commerce - T-Shirt Jumping Bear

Este é um projeto de desenvolvimento front-end realizado como o primeiro desafio prático no programa **Former 2026**, em parceria com a **Performa IT**. O objetivo foi replicar uma página de produto de um e-commerce real, focando em semântica HTML e estilização avançada com CSS.

## 🚀 Tecnologias Utilizadas

*   **HTML5**: Estrutura robusta com foco em semântica.
*   **CSS3**: 
    *   **Flexbox**: Utilizado no cabeçalho e rodapé para distribuição dinâmica.
    *   **Grid Layout**: Aplicado na vitrine de produtos e seções de comentários.
    *   **Responsividade**: Preparado para diferentes tamanhos de tela.
*   **Google Fonts**: Utilização da fonte *Poppins* para uma tipografia moderna.
*   **Flaticon UIcons**: Ícones vetoriais para interface de usuário e redes sociais.

## 🛠️ Funcionalidades Implementadas

*   **Header Dinâmico**: Barra de frete grátis, menu de navegação e busca integrada.
*   **Galeria de Fotos**: Visualização do produto principal com suporte a miniaturas.
*   **Seleção de Atributos**: Sistema visual para escolha de tamanhos e paleta de cores.
*   **Seção de Sugestões**: Vitrine "Você também pode gostar" com cards de produtos.
*   **Área de Avaliações**: Sistema de estrelas e comentários de clientes com selo de compra verificada.
*   **Footer Profissional**: Newsletter funcional, links institucionais, ícones de redes sociais e selos de segurança.
